Governed HR workflow

Resolve: PeopleOps Resolution Agent

A rules-based prototype of the controls an HR agent needs: it carries a request from intake to a cited recommendation, a named human approval, and an audit trail. No language model yet, and a held-out test shows where one is needed.

Workflow designHuman in the loopEvaluationMCP
View repository ↗︎ Try synthetic-data demo ↗︎ Review evaluation evidence ↗︎
Read case study +

Challenge

HR resolution is intake, authorization, evidence, judgment, action, and learning, not a single answer. Most agent demos skip the parts that make it safe: what the system may read, when it must stop, and who approves.

Approach

Defined the use case and operating requirements, designed the workflow and human-review model, and built the prototype with AI-assisted development. Safety screening, eligibility, policy selection, and approval are ordinary code, so every decision is reproducible. The MCP interface gives a connected model no way to approve its own recommendation.

Outcome

Passes its 60-case regression suite. A separate set of 16 realistically phrased requests passes 0 of 16, and four Employee Relations or legal concerns go unescalated. That result defines the job for a language-model classifier and the bar it must clear. Synthetic data; production would also need authenticated identities and role-based authorization.
