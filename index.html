Problem

HR teams need a shared path from an AI idea to a scoped workflow, accountable owners, and a reasoned pilot decision.

Approach

Defined the HR operating problems and designed an HRIS-agnostic system of templates, prompts, notebooks, governance checks, workflow patterns, and evaluations. Built the implementation with AI-assisted development and documented where specialist review remains necessary.

Result

A public, MIT-licensed reference toolkit with inspectable examples. Adoption, employee outcomes, and production readiness have not been demonstrated.

Resolve: HR Workflow and Judgment

A rules-based demonstration with fictional policy references, simulated review, and temporary activity history. Reviewer identities are self-reported. An optional model screen is separate from the browser demo. Known routing failures keep production use withheld.

Challenge

A correctly identified HR topic can still hide a concern requiring specialist handling. The design question is where automation should stop and a person should take ownership.

Approach

Defined the use case and operating requirements, designed the workflow and human-review model, and built the prototype with AI-assisted development. Rules enforce eligibility, policy selection, and approval state. An optional model screen can add routing to a person, but cannot clear a rules stop or approve an outcome. The MCP facade exposes no approval tool. The HTTP review path still lacks authenticated reviewer authority, so this is not end-to-end authorization.

Outcome

The original rules passed 60 of 60 regression cases and 0 of 16 realistically phrased requests. Five Employee Relations or legal concerns missed specialist routing: four received clarification responses, and one entered routine relocation review behind an approval gate. That set has since informed development. Early model-screen results use developer-authored cases and do not establish independent validation. Production use remains withheld pending fresh practitioner-written evaluation. Built on synthetic data.
