A portfolio for HR and AI leaders reviewing my independent project work.
Explore the design choices, executable examples, and limits behind each case study.

## Selected work

- **[HR AI Transformation Playbook](https://github.com/ellehelvig/hr-ai-transformation-playbook):** use-case selection, work redesign, governance, and adoption materials with synthetic demonstrations.
- **[Resolve](https://github.com/ellehelvig/peopleops-resolution-agent):** fictional HR requests, policy references, simulated human review, and published routing failures. Production use is withheld.

- **[Work Experiment Lab](https://elle-helvig-work-experiment-lab.lovable.app):** a public synthetic demonstration of prioritization, experiment design, accuracy gating, and simulated decisions. Its source remains private; no actual study or AI calls are claimed.

The site uses static HTML and CSS. It presents reference designs and synthetic demonstrations, with no measured business outcomes or production-readiness claim.

## Preview locally

Requires Python 3. From a directory where you want the clone:

```bash
git clone https://github.com/ellehelvig/ellehelvig.github.io.git
cd ellehelvig.github.io
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000). Stop the server with Ctrl+C.

## Maintain the site

Edit `index.html` for copy and case studies, and `styles.css` for layout. Check desktop, mobile, keyboard navigation, and disclosures before proposing publication. GitHub Pages deploys the default branch after merge; a review branch is not the live site.

Link to current project evidence instead of copying test counts into this site. Use fictional examples only. Keep private source material and real HR data outside the repository.
